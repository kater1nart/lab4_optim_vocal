## 2. Паспорт данных

| Параметр | Значение |
|---|---|
| Источник | MagnaTagATune (CC BY-NC-SA 3.0); метки типа вокала и разбиение по исполнителям — ЛР1; временной ряд — ЛР2 (`features.py`) |
| Объект | 10-секундное окно клипа → матрица 20 шагов (по 0,5 с) × 20 признаков: RMS (дБ), спектральные центроид / полоса / спад / плоскостность, ZCR, основной тон (YIN), MFCC 1–13 |
| Длина последовательности | фиксированная (20 шагов) у всех объектов; пропусков и NaN нет |
| Классы | instrumental 34,6%, male 26,1%, female 25,0%, group 14,3% (одинаковые доли в train / val / test ± 0,4 п.п.) |
| Разбиение (зафиксировано в ЛР1) | train 5 071 (163 исполнителя) / val 1 019 (34) / test 1 009 (33); исполнители не пересекаются |
| Дубликаты | точных нет; в среднем 2,1 клипа на трек (соседние сегменты одного трека — зависимые объекты); 3 почти-дубликата удалены в ЛР1 |
| Предобработка | z-нормировка каждого признака по среднему и std **только train**; взвешивание классов в loss (обратно пропорционально частоте) |
| Проблемы качества | слабая разметка (краудсорсинговые теги); сцепление класса с жанром; зависимость клипов одного исполнителя (i.i.d. нарушено) → блочный bootstrap |

**Аналог «длины текста и дубликатов» для нашего входа.** Длина ряда фиксирована, поэтому вместо распределения длины контролируются фиксированное окно (первые 10 с клипа) и зависимые объекты внутри трека и исполнителя.

## 3. Карта источников случайности

| Источник | Где возникает | Как управляется | Как измерен вклад |
|---|---|---|---|
| Инициализация весов | GRU и линейный слой | `init_seed` → `torch.manual_seed` перед созданием модели | фаза D: меняется только init (10 значений), остальное фиксировано |
| Порядок mini-batch | перестановка train в каждой эпохе | отдельный генератор `order_seed` | фаза D: меняется только порядок |
| Dropout | маски dropout 0,2 перед классификатором | глобальный RNG после инициализации (`dropout_seed`) | фаза D: меняется только dropout |
| Mini-batch шум градиента | оценка градиента по 64 объектам | размер батча | шум ‖g_b − G‖² / ‖G‖²; sensitivity по batch {32, 64, 128, 256} |
| Выборка обучающих данных | какие исполнители попали в обучение | bootstrap исполнителей train (10 повторов) | фаза E |
| Выборка тестовых данных | какие 33 исполнителя в тесте | фиксирована | блочный bootstrap исполнителей теста (500 повторов) |
| Подбор learning rate | дискретная сетка, 3 seed | одинаковая процедура для всех + правило расширения на краю | журнал `A_lr_tuning_all.csv` |
| «Режим» входного ряда | шум записи, громкость, деградация сигнала | стохастические сценарии OU / GBM / Markov-switching на тесте | фаза B (5 реализаций на модель) |

В финальных запусках (фаза B) для одного seed init, порядок и dropout совпадают у всех оптимизаторов. Поэтому сравнения по seed **спаренные**: различается только оптимизатор.
